# Достижения (Achievements)

Стена значков в Профиле, рядом с уровнем: слева карточка уровня (70% ширины),
справа плитка достижений (30%) с последним полученным значком и счётчиком.
Тап по плитке открывает всю стену; тап по значку — крупный вид, где значок
вращается сам и его можно крутить пальцем.

## Откуда берутся данные

`achievements(userId)` в `src/db.ts` выводит всё из **реальной истории** —
`generations`, `events`, `ledger`, `users` — а НЕ из `xp_claims`.

Это не стилистическое предпочтение. `xp_claims` заполняется только пока
настроена XP-экономика (`awardXpOnce` читает конфиг первым и выходит, если
награда не задана). Стена, построенная на нём, была бы сегодня пустой и —
хуже — **никогда бы не восстановилась**: реальная история пользователя
навсегда осталась бы вне его профиля. Вывод из первичных таблиц стоит
нескольких дешёвых агрегатов и ретроактивен по построению.

Заблокированные значки тоже возвращаются, с прогрессом. Пустые места — это то,
что придаёт вес полученным, и заодно самое понятное описание возможностей
продукта.

## Как выглядит значок

Значок собран из CSS, а не из картинки: он должен быть верным и на 44px в
плитке, и на 190px во вращении, на любом DPI, и стена обязана отрисоваться
целиком на первом кадре — до того, как что-либо скачается.

Слои, изнутри наружу:

- `.bgcore` — металл: конический градиент со смещённым центром, чтобы блик
  лежал там, где его поймала бы настоящая фаска;
- `.bgrim` — фаска: светлая кромка с освещённой стороны, тёмная с теневой —
  именно это говорит глазу «металл, у него есть толщина»;
- `.bgface` — глиф, поднятый по оси Z, поэтому при повороте он даёт параллакс
  относительно металла (это и продаёт объём);
- `.bgholo` — интерференционный отблеск, широкая диагональная полоса, идущая
  по поверхности.

Силуэт — щит (`clip-path`), а не скруглённый квадрат: именно контур читается
как награда на 44px, когда деталей ещё не разобрать.

Заблокированный значок сохраняет геометрию и теряет цвет — стена читается как
один набор с дырами, а не как две несвязанные группы.

## Замена глифов на настоящую графику

Глиф рисуется всегда; сверху накладывается `/img/badge-<id>.png` и удаляет
глиф по `onload`. Если файла нет — `onerror` убирает картинку, глиф остаётся.
Поэтому произведённую графику можно добавлять по одному файлу за раз, ничего
не переписывая, и набор никогда не выглядит сломанным.

### Бриф на генерацию (Higgsfield)

Требования, общие для всех значков — на них держится единство набора:

- **Один источник света**, сверху-слева, под тем же углом, что и CSS-фаска;
- **строго по центру, фронтально**, без перспективы — значок будет вращаться
  средствами приложения, и собственная перспектива картинки это сломает;
- **прозрачный фон**, PNG, квадрат 512×512, объект занимает ~62% кадра;
- **никакого текста** — надпись под значком уже есть в интерфейсе, и она
  локализуется;
- материал по тиру: bronze — тёплая патинированная бронза; silver —
  полированная сталь с холодным отражением; gold — глубокое золото с тёмными
  гранями (не жёлтый пластик).

Шаблон промпта:

```
Premium 3D achievement medallion icon, <СЮЖЕТ>, centred frontal view,
<МАТЕРИАЛ>, single soft key light from upper left, subtle iridescent
rim, deep bevelled edges, product-render quality, transparent background,
no text, no letters, square composition, object fills 62% of frame
```

`<СЮЖЕТ>` по значкам: камера с блендой (`first_render`), кинолента
(`ten_renders`), колоннада (`fifty_renders`), хлопушка (`first_video`), перо
(`first_text`), компас (`explorer`), набор инструментов (`polymath`), палитра
(`stylist`), раскрытая книга (`scenarist`), рамка с фотографией (`uploader`),
искра (`wordsmith`), антенна (`sharer`), билет (`first_purchase`), корона
(`patron`), рукопожатие (`inviter`), круг фигур (`circle`), треугольник из
трёх граней (`level_3`).

**Значки не генерируются из пользовательских фотографий.** Загруженные фото
собраны для одной цели — сделать пользователю результат — и повторное
использование их как оформления продукта не покрывается опубликованной
политикой конфиденциальности.
